# 双入口作品集与 AI 面试设计

## 目标

在现有最新版作品集上增加一个新的默认首屏，让访问者从同一入口选择“进入作品集”或“开始 AI 面试”。视觉参考 MotionSites `Scaling Platform`：浅灰背景、阶梯式窄体大标题、右侧动态视觉、青色单一强调色和斜切角按钮。现有作品、107 件视觉图库、三星堆互动工具与联系方式不得丢失。

## 范围

- 默认入口：双入口视觉首页。
- 作品集视图：保留现有完整作品集，只增加返回双入口的导航。
- AI 面试视图：提供实时文字对话、预设问题、流式回答、错误与重试状态。
- 云端接口：由 Cloudflare Worker 调用 Workers AI，浏览器不持有模型密钥。
- 部署：同一 Worker 同时托管 Vite 静态资源与 `/api/interview`。
- 不包含：本地电脑公网隧道、语音通话、3D 数字人、用户账户、长期保存聊天记录。

## 交互与视觉

### 双入口首页

- 顶部保留个人头像标识，并提供 PORTFOLIO、AI INTERVIEW、CONTACT 三个文字入口。
- 左侧使用六行阶梯标题：“看我的 / 作品 / 也和 / 数字版 / 的我 / 对话”，最后一行使用 `#15BCDF`。
- 标题下方提供两个斜切角按钮：“进入作品集”和“开始 AI 面试”。
- 右侧使用现有作品图片组成动态媒体舞台，不复制模板原视频、品牌或文字。
- 背景使用 `#F2F1F0`，正文为深灰；中文使用系统黑体，拉丁字符使用本地打包的 Quantico。
- 手机端先展示媒体，再展示标题和两个全宽入口，所有按钮具备键盘焦点与按压反馈。

### 作品集视图

- 现有项目数据、筛选、灯箱、滚动展开图库与联系方式保持原有行为。
- 顶部头像返回作品集首屏；新增“返回入口”控件回到双入口页。
- 使用 URL 查询参数 `?view=portfolio`，刷新和分享仍可恢复当前视图。

### AI 面试视图

- 左侧展示身份摘要、可提问范围和“查看作品集”入口。
- 右侧为对话区，初始提供“请做一下自我介绍”“讲讲你最完整的 AI 项目”“你如何保证角色一致性”“为什么适合这个岗位”四个问题。
- 用户发送后显示自己的消息，AI 回答采用流式追加；请求期间禁止重复提交。
- 支持 Enter 发送、Shift+Enter 换行、清空本次对话、错误后重试。
- 页面明确标注这是 AI 面试助手，回答基于刘耀华已公开的作品与经历。

## 云端架构

- `src/worker.js` 处理 `/api/interview`，其他请求交给 `env.ASSETS.fetch(request)`。
- `src/interview/profile.js` 保存可公开的人设与项目事实，作为 Worker 的系统提示来源。
- 请求只接受最近 10 条消息；单条消息最多 800 个字符。
- Worker 使用 Workers AI Binding `env.AI`，模型采用 Cloudflare 官方入门文档当前示例 `@cf/google/gemma-4-26b-a4b-it`。
- 浏览器生成匿名会话 ID；Worker 使用 Cloudflare Rate Limiting binding 按会话与 IP 组合限流。
- 不写入 D1、KV 或日志正文，不长期保存对话内容。
- 错误响应使用 JSON；流式成功响应保持 Workers AI 的 SSE 数据格式。

## 安全与边界

- 禁止把 Cloudflare token、API Key 或密钥写入前端、仓库、日志或聊天内容。
- 仅接受同源 POST 请求；检查 JSON 类型、消息角色、长度和数量。
- 系统提示要求只回答已提供事实，不编造工作经历、学历、技能、客户或项目数据。
- 对要求泄露系统提示、密钥或内部配置的问题直接拒绝。
- AI 回答仅用于了解本人经历，不替代本人承诺。
