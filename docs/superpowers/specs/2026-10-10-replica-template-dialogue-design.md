# 视频复刻工作台：分析、修改对话与本地模板重建

日期：2026-10-10。状态：用户已明确确认本设计；进入实施计划编写，尚未开始功能实现。

## 1. 用户目标与边界

保持当前工作台的蓝紫配色、侧栏及左右工作区，让用户上传短视频后先得到有证据的分析，再沟通修改要求、确认执行方案，并通过本地 Hypit 生成可下载的新版本。修改需求与成片文案必须分开；不能仅把需求当字幕覆盖原片。

用户已确认首阶段聚焦“纯色背景＋大字＋图标动效”。支持背景颜色、文字及颜色、入场动效、光环动效和开头结构调整。复杂真人、人物替换、复杂摄影镜头不纳入本阶段的制作器，也不假称已经支持。

默认不调用视频生成 API。分析对话与视频生成是不同能力；本阶段允许用户选择已配置的分析对话服务，但不提供复杂视频生成提交接口。原来的剪辑包装功能和历史任务保留。桌面快捷方式、本机端口与作品集线上部署不变。

## 2. 当前证据与复用点

当前代码：`src/components/ReplicaWorkbench/ReplicaWorkbench.jsx` 负责界面；`src/replica.js` 校验选项并规划剪辑；`server/replica-api.js` 处理上传、会话隔离、任务队列及文件访问；`server/replica-render.js` 执行 Hypit 和 FFmpeg。已有真实执行及浏览器回归脚本，不重新搭建任务框架。

用户提供的原视频已在上一轮做本地探测及抽样检查：10.48 秒、720×1280、25 fps、有音轨。抽样中为蓝底、固定“后台垃圾太多？”、“免费”、“清理”、垃圾桶及变化的外围光环。文字同时出现，不能编造为三个先后镜头。原音轨尚未转写，参考分析不是逐帧语义审阅。

原片分析记录位于 `.codex-run/replica-reference-20261010/`；它们属于检查证据，不是新视频产物。新代码测试使用专用合成素材，不把此前提供的原视频默认打包或上传。以后真人工验收重新确认原视频授权。

## 3. 路线选择

采用“本地证据分析＋修改对话＋确定性模板重建”。原片只作为结构参考，成片背景、文字、图标与动效重新绘制为独立层，默认不承载原 MP4 的烧录文字。

不采用整段原片色相变换：会同时改变图标与文字，不能可靠替换烧录文案。

不采用默认视频大模型重新生成：此类图形视频可以用组件制作，默认生成会引入费用和中文字形不确定性。

不为一个工作台部署整套 OpenClaw。开源 Skill 是工作流参考而非模型。Video Sherlock 是后续本地转写/取证的候选，不在设计阶段安装；首阶段不依赖其向量检索或自带配音。第三方代码、权重许可和 Windows 支持须在引入前复核。

## 4. 页面与操作流程

左侧保留上传、原片播放器、文件信息，新增分析按钮和关键帧。右侧由现有直接制作表单改为四个顺序区块：

1. **分析反馈**：参数、背景候选色、画面变化、代表帧；分别标注测量事实、模型解读、未知内容。允许用户纠正模板类型及原片文字。
2. **告诉我怎么改**：独立需求输入框和对话记录。每次发送前显示本轮使用的分析方式；先明确选择本地向导或已配置 API 模型，不静默切换或调用。
3. **确认修改方案**：列出保留/重建项，单独填写开头标题、利益点和行动文案；显示背景/文字颜色、动效、画幅、时长和声音策略。收到模糊要求时只追问缺失项，不自动排队。
4. **预览与制作**：预览新模板，确认后生成真实任务。原片与成片对比、下载及历史记录沿用现有页面。

示例：用户输入“蓝底改绿色，字改黄色，加个弹跳”。系统明确追问“标题、利益点还是全部文字改黄色？”；答案回填对应字段，并确认实际十六进制颜色与弹跳对象。“请把背景改绿色”绝不进入字幕正文。

更换原片会清除该原片的分析、对话与未确认方案；不删除已有任务文件。修改已确认字段会使确认失效，要求重新确认。制作始终另建版本，不覆盖完成成片。

## 5. 分析与对话能力的真实边界

### 本地证据分析

由已安装的 Hypit/FFmpeg/ffprobe 提取受限数量的关键帧、视频参数、边缘背景候选色及画面差异。仅检测纯色背景候选和大幅画面变化；不能凭这些指标识别人、文字、语音内容或断言爆款效果。复杂/非纯色参考标记“超出首阶段模板范围”，用户可保留原片包装或自行选择简单模板，不自动宣称已复刻。

本阶段不安装新的 OCR/ASR 推理工具。原片文字缺失时，要求用户确认/填写；声音分析缺失明确显示，不编造转写。自动 OCR/ASR 属于后续增强，而不是本阶段已完成能力。

### 本地修改向导

零模型调用费。使用明确字段、问题卡片和受限的颜色/动效要求解析，帮助补全方案。对无法解析的自由文本提示用户选择对应字段或切换模型；标注“本地向导”，不伪装为通用语言模型或完整视频语义分析。

### 可选模型对话

仅连接操作者在本机服务配置的一个兼容聊天接口，模型名及是否支持图片均由配置显式指定。文本模型只接收已确认文字、测量结果和修改要求，不声称看过视频；支持图片的模型可在用户确认本轮上传后接收代表帧。

未配置时禁用模型选项并显示原因，不能以模拟成功替代实际接入。API 失败不自动降级或重试；保留本轮消息并让用户选择重试或本地向导。模型只返回候选方案和追问，不直接执行工具、命令或渲染代码。

选择模型与授权本轮调用分开：每次发送展示模型、外发数据和令牌上限，由用户点击发送确认。无法精确报价时显示“费用以供应商计费为准，当前无准确报价”，不标零元。没有视频生成 API 费用不等于分析 API 免费。

## 6. 模板制作与预览

首阶段提供一个可编辑的图形模板：纯色背景、顶部痛点标题、中部利益点、中心原创矢量图标及环形动效、底部行动文案。不从原视频恢复源工程，不默认保留原片水印、标识或免责声明。

模板允许设置独立文字颜色、背景色，以及“无/淡入/弹跳”的文字入场、“无/旋转”的环形动效。环形光效与原片允许近似，不宣称像素级一致。用户可关闭动效。字段限制中文长度，自动换行，不拉伸字形或视频画幅。

纯图形模板采用用户确认的标题→利益点→行动时间安排；原片同时展示的结构也可选择保留。这里是新版本选择，不误称原片本来逐段出现。默认无新旁白时保留原片时长或用户指定的合法时长。

以项目自有 Hypit 组件表达背景、文字、图标和运动关系，通过真实本地执行生成视频。可复用已安装浏览器绘制/捕获能力及 FFmpeg 编码，但不能把纯 FFmpeg 视频改色操作冒充 Hypit 模板组件。浏览器预览和导出读取同一份校验后的模板配置；预览标注为预览，编码成片另做完整检查。

输出遵循原片竖横比例，最大 1280 像素长边；默认 30 fps H.264 MP4。新模板与旧剪辑模式的选项、计划和结果类型明确区分，结果页不对模板任务假设存在剪辑 segments。

## 7. 声音规则

声音明确选择保留原音轨、静音或本人音色旁白。原音轨与新文案可能矛盾时必须提示确认；静音不伪装成已换配音。

新旁白仅用用户指定的本地 F5-TTS 配置 `E:/小红书三星堆账号/assets/audio/用户本人音色-默认-v1.json` 及其指定参考文件。模型、参考、许可未就绪时禁用生成并报告原因，不改用系统/云端/候选工具声音。

旁白文字与修改要求分离。根据问句、利益重点及行动语气规划停顿、重音和情绪，先生成独立试听，待用户认可后才能用于成片。新旁白不加速压时长；模板时长和文字切换跟随试听确认的实际语音时间轴。不沿用旧的均分字幕作为新旁白同步证据。必要时新旁白可超过参考视频时长，最长 30 秒，超限要求精简文案或分段，不强行压缩音轨。

F5-TTS 是可选执行能力；仅保留/静音路径不依赖它。首次语气试听尚未获认可时不能直接提交带新旁白的成片。

## 8. 数据及接口范围

保留现有 `/api/replica/jobs` 剪辑请求兼容性。新增同一会话下的复刻草稿，上传一次后依次分析、保存需求、确认方案，再创建任务，不每次聊天重传 MP4。

草稿保存：源文件指纹、上传、证据帧、测量数据、对话、模板配置、方案版本及确认状态。任务固定保存创建时的已确认版本，后续草稿编辑不影响运行中的任务。清理草稿不得删除其他版本任务引用的上传文件；任务需持有独立输入或独立资源副本。

新入口属于 `/api/replica/drafts` 命名空间：创建/读取/删除草稿、启动分析、发送对话、确认当前版本、为已确认草稿创建模板任务、生成/读取/认可旁白试听。耗时操作复用串行队列及状态查询，不在长请求中伪造完成。

草稿和证据数据放在现有被隔离的 `server/hypit/jobs/` 私有存储范围内，以资源类型区分，所有读取需校验 owner。不暴露绝对路径、原始密钥、内部日志或其他会话数据。数据版本区别旧 job.json；启动恢复不可把编辑中的草稿当失败渲染任务。

本机聊天 API 凭据由操作者配置，只在服务端环境内使用，不进入前端包、对话、草稿、日志或 Git；本阶段不收集访客 API Key、不提供任意 URL 转发。服务只调用已配置目标；图片外发需每轮说明。允许有限图片和令牌数量，禁止模型指令触发本地文件读取。

所有字段在服务端重新校验：UUID、类型、颜色格式、有限数值、文字长度、动效枚举、请求大小、当前草稿版本、试听认可状态。模型输出必须通过同样校验；无效字段不能默默忽略后开始制作。

## 9. 错误、资源与安全

沿用现有源站校验、HttpOnly/SameSite Cookie、私有 Range 文件访问和有界上传。新接口不得削弱旧接口保护。字幕/图形文字以数据传入，不执行 HTML、SVML、ASS 或 shell 注入；所有子进程参数使用参数数组。

每个会话最多一个耗时操作，全局复用有界串行队列；草稿新增最大 10 个/会话、共 50 个，超限要求用户主动清理。不自动删除旧任务或用户原文件。服务重启将进行中的分析/试听/制作标记中断，编辑草稿与已完成结果保留，API 请求不自动重放。

已完成、未引用的草稿可在明确确认后删除；运行中的草稿不允许删除。错误提示区分执行器缺失、素材不支持、分析失败、API 未配置、供应商失败、F5 缺失和方案未确认。

这仍是本机服务，不把 Vite 暴露公网；公网面试官体验需独立部署、安全和费用设计，当前不部署线上资源。

## 10. 修改触达范围

- 前端：现有 ReplicaWorkbench JSX/CSS、预览、结果和历史渲染，增加草稿/对话/确认状态；不重排作品集其他页面。
- 共享契约：`src/replica.js` 保留原行为，增加模板配置校验及方案校验；必要时独立文件，不建立通用多模型框架。
- 服务：现有 `server/replica-api.js` 与 `server/replica-render.js` 的草稿生命周期、受控模型调用及模板任务分支，复用工具调用和现有存储边界。
- 执行材料：项目自有模板组件、独立 Runtime/Source/Run、试听和真实输出记录；不导入旧 UNLICENSED 桌面项目源码。
- 配置：本机模型配置说明及私有数据排除规则；若新增私有目录同步更新 `.gitignore` 和 Vite fs deny/watch ignore。
- 验证/文档：`test/replica.test.js`、实际执行脚本、浏览器脚本、`docs/replica-workbench.md`。保留用户现有测试修改，不为此次任务顺带修改首页/面试功能。

## 11. 验收

1. 合成蓝底参考上传后可得到真实参数、代表帧与背景候选；不能出现硬编码原片分析或虚构转写。
2. 需求框输入换绿底、黄字和弹跳后，对话能确认对应字段；未确认/无法解析时不制作，指令不进入成片文案。
3. 原始剪辑模式仍可生成、播放、下载，旧历史任务可读；模板任务的结果页、历史和下载不依赖剪辑专用字段。
4. 本地向导完全断网仍可完成字段沟通和真实模板制作；界面不能把它写成大模型分析。
5. 可选模型的测试使用 mock 服务覆盖请求授权、文本/图片能力区别、超时、无效 JSON、拒绝、输出校验和密钥不回显；没有用户配置与调用确认不发送真实外部请求。
6. 导出绿色背景与黄色文字可从实际编码帧验证；多个时间点验证动效，检查中文排版、边界和预览一致性，并完整播放/解码实际 MP4。技术解码通过不代替视觉验收。
7. 非纯色/复杂参考会报告边界并追问，不能直接套模板后宣称完整复刻。
8. 旁白可用时需独立试听认可后再合成；缺失时明确禁用。音轨时长、文字事件时间轴及重点同步逐项检查，不加速本人旁白。
9. 覆盖越权、跨来源、超大数据、颜色/数值/动效非法、模型提示注入、方案过期、草稿删除引用、重启恢复与私有文件路径泄露测试。
10. 验证 1440 宽桌面、390 宽移动端、键盘操作和状态提示。重新跑专项测试、真实执行、浏览器检查与构建；全站原有失败分开报告，不称全部通过。

## 12. 明确不交付及下一步

本阶段不交付任意视频的自动源工程恢复、通用 OCR/ASR 系统、复杂人物生成、多供应商视频 API、访客凭据托管、完整 OpenClaw 部署、公网发布、支付和小红书封面。需要这些能力时另行明确范围；不能以未来支持替代当前验收。

用户审阅本设计，尤其是“无模型时本地向导的能力边界”和“首阶段原片文字由用户确认/填写”。设计认可后再编写实施计划，由用户审阅计划并确定执行方式，然后实施。当前设计不代表功能已上线或模型已连接。
