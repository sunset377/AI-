# 达州升华 V4 门店演示

从已交付的 V4 网站复制，保留原模型与碰撞数据。公开地址：
https://sunset377.github.io/AI-/dazhou-store/

本目录独立使用 Three.js 0.186.1、Vite 8.3.3，需要 Node.js 22.12+。
在本目录执行 `npm ci`、`npm run build`，生成 `../../public/dazhou-store`。
提交源代码与生成结果；作品集原有 GitHub Pages 流程会复制该目录。
未改动模型几何，资源采用相对地址，避免部署在 `/AI-/` 子路径时出现 404。

仅发布网页、GLB、碰撞数据与演示预览；工程图、原始 PDF、视频、Blender 工程和本机日志留在本地。
无付费生成或外部 API。模型是前期方案预演白模，墙厚、部分洞口尺寸仍为暂定值，不是施工交付。

桌面拖动旋转、滚轮缩放，点击进入后 WASD/方向键移动、鼠标转向；Esc 退出。
手机点击进入后使用方向按钮，拖动画布转向。
